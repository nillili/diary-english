# 일기 기반 영어회화 애플리케이션 의도 및 의사코드

## 1. 핵심 목적과 확정 사항

**오늘의 일기를 영어회화 학습용 MP3로 만들어 보관하고, 나중에도 반복해서 듣는 Python 데스크톱 앱**을 만든다. 일회성 번역보다 음성 파일의 저장과 재학습이 핵심이다.

- 오늘의 일기를 2~3줄 작성하는 입력창과 영어 번역 결과창을 둔다.
- 입력창 바로 아래의 **변환** 버튼을 눌러야 번역과 음성 생성이 시작된다.
- 환경설정에서 미국식 영어의 회화 스타일과 남성/여성 음성을 선택한다.
- 기본 회화 스타일은 미국 중년층의 자연스러운 일상회화다.
- 재생/일시정지는 한 버튼으로 전환하고, **정지 버튼은 따로 둔다.**
- 한 번에 한 문장을 듣는다. `R`은 현재 문장 반복, `Space`는 다음 문장 재생이다.
- 생성한 MP3는 영구 보관하고 앱을 다시 실행해도 학습할 수 있어야 한다.
- 무료로 사용할 수 있는 GitHub 공개 도구를 우선 검토한다.
- 이후 기술 변경을 고려하여 화면, 번역, 음성 생성, 저장, 재생을 분리한다.

현재는 설계 문서 단계다. 아래 도구 조합, 세부 기본값과 화면은 구현을 위한 제안이며 실제 설치·변환·음질 테스트를 마친 상태는 아니다.

### 추천하는 초기 조합

**Python 데스크톱 화면 + Ollama의 로컬 언어 모델 + edge-tts + 로컬 학습 보관함**을 우선 검증한다. 이는 위 기능을 바탕으로 한 설계 판단이며, 번역·음성 품질 검증 결과는 아니다.

- 회화 스타일은 번역 모델에 지시하고, 음성 성별은 음성 엔진의 실제 지원 음성에서 선택한다.
- edge-tts 사용 시 번역된 문장이 외부 음성 서비스로 전송된다. 설정 화면에 온라인 음성 생성임을 표시한다.
- 완전 로컬 구성이 필요하면 음성 엔진을 Kokoro로 교체하는 방안을 검증한다.
- 저장된 자료를 다시 들을 때는 번역·음성 서비스를 호출하지 않는다. 인터넷 없이도 재학습할 수 있게 한다.
- 실행 모델은 사용자 PC의 메모리와 GPU 유무를 확인한 후 선택한다. 특정 모델의 품질이나 실행 속도를 미리 보장하지 않는다.

## 3. 미국식 영어 스타일과 음성 옵션

### 추가 확인: 기존 MeloTTS 활용 가능성

사용자가 기존 프로그램에서 사용 중인 [myshell-ai/MeloTTS](https://github.com/myshell-ai/MeloTTS)는 **영어와 미국식 발음을 지원한다.** 공식 안내에는 미국·영국·인도·호주 영어 및 기본 영어 음성이 있다. 기존 사용 경험을 활용할 수 있으므로 영어 음성 생성의 우선 검증 후보에 추가한다. 기존 edge-tts 추천은 비교 후보로 유지하고, 실제 선택은 영어 샘플과 음성 선택 요구를 확인한 뒤 결정한다.

- 공식 Python 예제는 `TTS(language='EN')`과 `speaker_ids['EN-US']`로 미국식 영어를 생성한다. 속도 조절도 가능하다. [공식 사용법](https://github.com/myshell-ai/MeloTTS/blob/main/docs/install.md#python-api)
- MeloTTS는 텍스트를 음성으로 읽는 역할이다. 한국어 일기를 미국식 회화로 번역하는 단계는 별도로 필요하다.
- 사용자는 기존 프로그램에서 **MeloTTS로 생성한 음성을 `soundfile`로 파일에 저장**해 사용하고 있다. 이 구성을 재사용하는 방향으로 우선 검증한다. MeloTTS API도 파일 저장을 SoundFile에 위임한다. [파일 저장 구현](https://github.com/myshell-ai/MeloTTS/blob/main/melo/api.py)
- SoundFile 공식 문서에는 MP3 쓰기 예제가 있다. 따라서 WAV 중간 파일을 필수로 두지 않고 **MeloTTS의 음성 배열 → `soundfile.write()` → MP3** 직접 저장을 우선 검증한다. 실제 지원은 설치된 SoundFile 및 libsndfile 버전·빌드에 따라 확인하며, 직접 저장이 불가능한 환경에서만 WAV 후 별도 MP3 인코딩을 대안으로 사용한다. [SoundFile 공식 문서](https://github.com/bastibe/python-soundfile#controlling-bitrate-mode-and-compression-level)
- 공식 영어 화자 목록은 억양별로 구분되어 있으며, 미국 영어 남성·여성 한 쌍을 선택하는 기능은 해당 문서에서 확인되지 않는다. 남녀 선택 요구는 유지하되 MeloTTS만으로 충족한다고 가정하지 않는다. 필요하면 다른 음성 엔진을 함께 제공한다.
- 영어 모델과 필요한 리소스 준비 후 로컬 실행을 검증한다. 기존 한국어 모델 설치만으로 영어 모델까지 준비되어 있다고 가정하지 않는다.
- 아래 예제는 공식 API 형태를 따른 참고 코드이며 현재 환경에서 실행한 결과는 아니다.

```python
from melo.api import TTS
import soundfile as sf

model = TTS(language="EN", device="auto")
speaker_ids = model.hps.data.spk2id
audio = model.tts_to_file(
    "I took a walk in the park after work today.",
    speaker_ids["EN-US"],
    output_path=None,
    speed=1.0,
)
sf.write("sentence_001.mp3", audio, model.hps.data.sampling_rate, format="MP3")
# MP3 쓰기를 지원하는 환경에서 실행한다. 생성 후 읽기·재생을 검증한다.
```

### 회화 스타일 구성

초기 출력 언어는 미국식 영어로 두고, 아래 회화 스타일을 제안한다. 다른 출력 언어 추가는 확장 항목으로 남긴다.

| 스타일 | 번역 지침 |
| --- | --- |
| 중년층 일상회화 — 기본 | 차분하고 친숙한 표현. 과도한 유행어와 격식체를 피함 |
| 쉬운 일상회화 | 짧은 문장과 쉬운 어휘 중심 |
| 친근한 캐주얼 | 친구와 이야기하는 자연스러운 말투 |
| 정중한 일상회화 | 낯선 사람이나 이웃에게 말하기 좋은 정중한 표현 |
| 직장 일상회화 | 동료와 대화하기 적절한 표현 |

공통 규칙은 원문의 사건·시제·감정을 유지하고, 원문에 없는 상황을 만들어 넣지 않는 것이다. 여기서 스타일은 **번역 표현 방식**이다. 특정 나이의 목소리나 감정 연기를 음성 엔진이 지원한다는 뜻은 아니다.

음성 옵션은 남성/여성, 해당 조건에 맞는 미국 영어 음성, 생성 속도로 구성한다. 지원하지 않는 음성은 선택 목록에 표시하지 않는다. 설정 변경은 다음 변환부터 적용하며 기존 MP3는 그대로 보존한다.

## 4. 예상 화면 디자인 — 한글 + ASCII

테두리는 ASCII 문자 `+`, `-`, `|`로 표현했다. `[버튼]`, `[선택값 v]`, `(o)`는 각각 버튼, 선택 목록, 선택된 항목을 뜻한다. 한글을 포함하므로 표시 환경의 글꼴에 따라 테두리 정렬은 조금 다를 수 있다.

### 4-1. 오늘의 학습 탭

```text
+----------------------------------------------------------------------+
| 나의 일기 영어회화                                           [_][X] |
+----------------------------------------------------------------------+
| [오늘의 학습]   [학습 보관함]   [환경설정]                             |
+----------------------------------------------------------------------+
| 오늘의 일기                                      날짜: 2026-09-24    |
| +------------------------------------------------------------------+ |
| | 오늘은 퇴근하고 동네 공원을 걸었다.                                | |
| | 날씨가 선선해서 기분이 좋았다.                                     | |
| |                                                                  | |
| +------------------------------------------------------------------+ |
| [변환]                                                               |
| 미국식 영어 / 중년층 일상회화 / 여성 음성                             |
|                                                                      |
| 영어 번역                                                           |
| +------------------------------------------------------------------+ |
| | > 1. I took a walk in the park after work today.                   | |
| |   2. The cool weather put me in a good mood.                       | |
| |                                                                  | |
| +------------------------------------------------------------------+ |
| 현재 문장: 1 / 2                          상태: 재생 대기             |
|                                                                      |
| [재생 / 일시정지]   [정지]                                            |
| R: 현재 문장 다시 듣기     Space: 다음 문장                            |
| 한 문장이 끝나면 기다립니다.                                         |
+----------------------------------------------------------------------+
| 변환 완료: 아직 저장하지 않았습니다.                                 |
| [저장]                                                               |
+----------------------------------------------------------------------+
```

- 번역 결과는 읽기 전용이며 현재 문장을 강조한다. 위 영어는 화면 설명용 예문이다.
- 변환 버튼은 번역과 음성을 생성하여 임시 결과로 준비한다. 하단에는 `[저장]` 버튼 하나만 둔다.
- `[저장]`을 누르면 환경설정의 저장 위치에 원문·번역·문장별 MP3·전체 MP3를 함께 보관한다. 성공 후에만 저장 완료를 표시한다.
- 재생 중에는 버튼에 `일시정지`, 그 외에는 `재생`을 표시한다.
- 입력 중의 R과 Space는 글자로 입력된다. 재생 영역에 초점을 둔 경우에만 단축키로 동작한다.
- 변환 중에는 `번역 중`, `음성 생성 중: 1/2`를, 저장 버튼 처리 중에는 `저장 중`을 표시한다.
- 초기 상태나 변환 중에는 사용 불가능한 재생·저장 버튼을 비활성화한다.

### 4-2. 학습 보관함 탭 — 저장 자료로 다시 학습

```text
+----------------------------------------------------------------------+
| 나의 일기 영어회화                                           [_][X] |
+----------------------------------------------------------------------+
| [오늘의 학습]   [학습 보관함]   [환경설정]                             |
+----------------------------------------------------------------------+
| 검색: [날짜 또는 일기 내용                         ] [찾기]           |
|                                                                      |
| +------------+----------------------+----------+-------------------+  |
| | 날짜       | 제목                 | 문장 수  | 회화 스타일       |  |
| +------------+----------------------+----------+-------------------+  |
| | 2026-09-24 | 퇴근길 산책          | 2        | 중년층 일상회화   |  |
| | 2026-09-23 | 친구와 점심          | 3        | 친근한 캐주얼     |  |
| | 2026-09-22 | 주말 장보기          | 3        | 쉬운 일상회화     |  |
| +------------+----------------------+----------+-------------------+  |
|                                                                      |
| 선택한 자료: 퇴근길 산책                                             |

+----------------------------------------------------------------------+

```

목록 항목을 한 번 클릭하면 첫 번째 `오늘의 학습` 탭으로 바로 이동하고 저장된 원문·번역·음성을 불러온다. 첫 문장을 선택하고 재생 대기한다. 제목은 처음에는 일기 첫 줄에서 짧게 만들며 제목 변경은 추후 확장할 수 있다.

초기 지원 언어가 하나라면 입력·출력 언어는 고정 표시해도 된다. 저장 위치 변경은 새 자료부터 적용하며 기존 자료를 자동 이동하지 않는다. 기존 보관 위치도 기억해 보관함에서 계속 조회한다.

## 5. 핵심: MP3 보관과 재학습 설계

### 저장 산출물

새 변환 결과를 저장할 때마다 고유한 학습 폴더를 만든다. 같은 날 다시 변환해도 기존 자료를 덮어쓰지 않는다.

```text
학습자료/
+-- 2026-09-24_204500_a1b2c3/
|   +-- original.txt         # 원문 일기
|   +-- translation.txt      # 번역문
|   +-- manifest.json        # 문장 순서, 상대 파일 경로, 설정, 제목
|   +-- full.mp3             # 외부 플레이어용 전체 듣기 파일
|   +-- sentences/
|       +-- 001.mp3
|       +-- 002.mp3
+-- 2026-09-25_193000_d4e5f6/
    +-- ...
```

- **문장별 MP3**: 앱의 R 반복과 Space 이동에 사용한다.
- **전체 MP3**: 문장별 음성을 순서대로 합쳐 일반 음악 플레이어에서도 들을 수 있게 한다. 문장 사이 기본 간격은 1초를 제안한다.
- 전체 파일은 음성을 디코딩하고 간격을 넣어 다시 MP3로 인코딩한다. 단순한 파일 바이트 연결은 하지 않는다.
- `manifest.json`에는 자료 ID, 생성 일시, 제목, 원문·번역 파일 경로, 문장별 텍스트·음성 경로, 출력 언어, 회화 스타일, 음성 엔진·음성 ID·생성 속도, 번역 모델 식별자를 기록한다.
- 경로는 학습 폴더 기준 상대 경로로 저장하여 폴더를 복사해도 연결을 유지한다.
- 앱 재학습에는 문장별 파일과 메타데이터를 사용한다. 전체 MP3만 복사한 경우에는 외부 플레이어에서 전체 듣기가 가능하다.

### 저장 성공과 실패

1. 변환 시 임시 작업 폴더에서 원문·번역·음성을 준비한다. 아직 보관함에 등록하지 않는다.
2. 문장별 파일과 전체 MP3가 존재하고 실제로 읽을 수 있는지 확인한다.
3. `[저장]`을 누르면 저장 위치에 파일과 메타데이터를 기록하고 검증한다. 완성된 폴더로 확정한 뒤 보관함에 등록한다.
4. 번역·음성 생성·디스크 저장 중 실패하면 완료로 표시하지 않는다. 재시도에 쓸 수 있는 중간 결과는 유지하고 실패한 단계를 안내한다.
5. 앱이 종료되었다가 다시 열려도 불완전한 작업 폴더는 완성된 자료 목록에 넣지 않는다.
6. 기존 자료의 파일이 없어졌다면 해당 파일과 복구 안내를 표시하며, 사용자 조작 없이 다시 생성하거나 덮어쓰지 않는다.

영구 보관은 `[저장]` 클릭으로 수행하며 재번역·음성 재생성을 하지 않는다. 저장 대상은 현재 변환 결과와 변환 당시의 원문·옵션이다. 이미 저장한 결과는 저장 버튼을 비활성화해 중복 저장을 막는다. 저장 실패 시 임시 결과를 유지하고 재시도를 허용한다.

미저장 결과나 편집 초안이 있는 상태에서 보관 자료를 클릭하거나 새 변환·앱 종료를 시도하면, 저장 또는 계속 편집할 수 있게 안내한다. 사용자가 버리기를 선택하기 전에는 해당 내용을 유지한다. 미저장 내용이 없는 일반적인 보관함 클릭은 확인 창 없이 즉시 이동한다.

## 6. 재생 규칙과 내부 구성

- 재생: 현재 문장 한 개를 재생한다. 일시정지 상태면 멈춘 위치부터 이어 듣는다.
- 일시정지: 현재 위치에서 멈춘다.
- 정지: 현재 문장의 처음으로 되돌리고 대기한다.
- 문장 종료: 자동으로 다음 문장으로 넘어가지 않는다.
- R: 재생을 중단하고 현재 문장을 처음부터 다시 재생한다.
- Space: 현재 재생을 중단하고 다음 문장을 재생한다.
- 마지막 문장의 Space: 첫 문장으로 돌아가 처음부터 재생한다.
- 보관 자료를 열거나 새 변환을 시작할 때 기존 재생을 중지한다.
- 입력·옵션 변경만으로 기존 음성이 바뀌지 않는다. 다시 변환하면 별도 자료를 만든다.

| 구성 요소 | 책임 |
| --- | --- |
| 데스크톱 화면 | 두 텍스트박스, 버튼, 탭, 진행·오류 상태 |
| 번역 서비스 | 원문 의미 보존 및 선택한 미국식 회화 스타일 적용 |
| 문장 처리 | 약어·소수점 등을 고려한 문장 분리 및 순서 관리 |
| 음성 서비스 | 각 문장 음성 생성, 필요 시 MP3 인코딩 |
| 저장소 | 원문·번역·MP3·메타데이터 보관, 보관함 조회 |
| 재생 관리자 | 문장 선택, 재생 위치, 반복 및 다음 문장 이동 |

시간이 걸리는 번역·음성 생성·인코딩은 백그라운드에서 실행한다. 변환 또는 저장 중에는 중복 실행, 자료 전환과 재생을 막고 진행 상태를 표시한다. UI 도구 및 MP3 재생·인코딩 라이브러리는 대상 운영체제를 확인하고 선정한다.

## 7. 의사코드

```text
앱_시작:
    저장된 환경설정과 보관 위치 목록 읽기
    완성된 학습 폴더의 메타데이터로 보관함 구성
    결과가 없으면 재생과 저장 비활성화

변환_버튼_클릭:
    빈 입력이거나 변환 또는 저장 중이면 종료
    미저장 결과나 편집 초안이 있으면 내용 소실 방지 처리
    기존 재생 중지
    입력과 옵션을 작업용으로 복사
    변환 중 상태로 전환하고 중복 조작 비활성화

    백그라운드에서:
        고유 ID와 임시 저장 폴더 만들기
        선택한 미국식 회화 스타일로 번역
        문장 목록 만들기; 빈 결과이면 실패 처리
        각 문장 음성 생성 후 MP3로 저장
        문장 음성들 사이에 간격을 넣어 전체 MP3 만들기
        원문, 번역, 메타데이터 기록
        파일 읽기 가능 여부와 문장-음성 대응 확인
        임시 결과로 유지; 아직 영구 보관하지 않음

    성공 시 UI에서:
        새 임시 결과를 학습 화면에 적용
        첫 문장 선택, 재생 대기
        변환 완료 및 미저장 상태 표시; 저장 버튼 활성화

    실패 시 UI에서:
        실패 단계와 재시도 안내
        기존 완성 자료는 유지
        새 결과를 저장 완료로 표시하지 않음

    항상 UI에서:
        변환 중 상태 해제
        완성 자료 유무에 맞게 버튼 활성화

보관함_목록_항목_클릭:
    변환 또는 저장 중이면 종료
    미저장 결과나 편집 초안이 있으면 내용 소실 방지 처리
    기존 재생 중지
    첫 번째 오늘의 학습 탭으로 이동
    선택한 자료의 원문, 번역, 문장별 MP3 확인
    누락되거나 손상된 파일이 있으면 해당 문제 표시
    정상 자료이면 원문·번역·음성을 적용하고 첫 문장을 선택하여 대기
    저장 완료 상태 표시; 저장 버튼 비활성화
    번역 및 음성 생성 서비스는 호출하지 않음

재생_일시정지_버튼:
    재생 중이면 현재 위치에서 일시정지
    일시정지 상태이면 이어서 재생
    대기 상태이면 현재 문장 처음부터 재생

정지_버튼:
    현재 재생 중지
    현재 문장 재생 위치를 처음으로 초기화

문장_종료:
    현재 문장을 유지하고 대기

R_또는_Space:
    입력 영역이면 일반 문자로 처리
    변환 중이거나 재생 영역에 초점이 없거나 자료가 없으면 종료
    R이면 현재 문장 처음부터 재생
    Space이면 다음 문장으로 이동하여 재생 (마지막 문장이면 첫 문장으로)

저장_버튼_클릭:
    결과가 없거나 이미 저장했거나 변환 또는 저장 중이면 종료
    저장 중 상태로 전환; 중복 실행 및 자료 전환 비활성화
    백그라운드에서 현재 결과의 파일과 메타데이터를 저장 위치에 기록
    파일 검증 후 고유 학습 폴더로 확정
    성공하면 보관함 등록, 저장 완료 표시, 저장 버튼 비활성화
    실패하면 임시 결과 유지, 오류 안내, 저장 재시도 허용
    항상 저장 중 상태 해제
```

## 8. 구현 시 검증 기준

- 변환 버튼을 눌러야 번역과 음성이 생성되는가?
- 스타일을 바꿔도 원문의 의미·시제가 유지되고 없는 내용이 추가되지 않는가?
- 미국식 영어 음성과 남성/여성 선택이 실제 생성 결과에 반영되는가?
- 문장 단위 재생, 일시정지·정지, R 반복, Space 이동이 규칙대로 작동하는가?
- 텍스트 입력 중 단축키가 학습을 방해하지 않는가?
- 문장별 MP3와 전체 MP3를 일반 플레이어에서 열 수 있는가?
- 앱을 종료한 뒤 인터넷을 끊고 다시 실행해도 보관 자료로 학습할 수 있는가?
- 같은 날 여러 번 변환해도 이전 자료가 보존되는가?
- 저장 버튼을 눌러야 보관함에 등록되고 중복 저장이 방지되는가?
- 보관함 목록을 클릭하면 첫 번째 탭에 해당 자료가 표시되는가?
- 미저장 결과와 편집 초안이 자료 전환으로 소실되지 않는가?
- 저장 실패 시 완료로 잘못 표시하지 않고 재시도할 수 있는가?
- 학습 폴더를 복사해도 상대 경로를 통해 문장과 음성의 대응이 유지되는가?

## 9. 구현 전에 남은 확인 사항

1. 대상 운영체제는 Windows, macOS, Linux 중 무엇인가?
2. 사용할 PC의 RAM 용량과 GPU 유무는 무엇인가? 로컬 번역 모델 선정에 필요하다.

데스크톱 앱, 별도 정지 버튼, 미국식 영어 스타일 선택, MP3 영구 보관은 확정 사항이므로 다시 확인하지 않는다.
