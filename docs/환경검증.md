## 3. 설치 중 만난 문제와 조치

| 문제 | 조치 |
| --- | --- |
| Ollama 최신 배포가 `.tgz` → `.tar.zst` 로 바뀌어 기존 주소 404 | GitHub 릴리스 v0.34.4 `ollama-linux-amd64.tar.zst` 사용 |
| librosa 0.9.1 이 `pkg_resources` import → setuptools 81+ 에서 실패 | `setuptools<81` 고정 |
| MeloTTS 영어 처리에 NLTK 데이터 필요 | `averaged_perceptron_tagger_eng`, `averaged_perceptron_tagger`, `cmudict` 를 `envs/diary_en/nltk_data` 에 설치 |
| unidic 사전 필요 | `python -m unidic download` |
| **한글 입력 안 됨** (입력기 fcitx 4). pip PySide6 에는 fcitx 플러그인이 없고, 시스템 플러그인(Qt 6.4.2 빌드)은 6.11 에서 비공개 API 불일치로 로드 실패 | PySide6 를 시스템 Qt 와 같은 6.4.2 로 고정하고 `libfcitxplatforminputcontextplugin-qt6.so` 를 PySide6 플러그인 폴더에 복사. 플러그인 로드·MP3 재생(EndOfMedia 까지)·테스트 92개 통과 확인 |
| 첫 실행 시 MeloTTS 영어 모델·BERT 가중치 다운로드 | Hugging Face 캐시(`~/.cache/huggingface`)에 저장. 이후 오프라인 로딩 |

## 4. 기능별 확인 결과 (도구 검증)

| 항목 | 결과 |

## 5. 번역 모델 비교 (사람 검수용 원자료)

예문 3개 × 중년층 일상회화, `scripts/smoke_translation.py`.

| 예문 | qwen3:4b | qwen2.5:7b |
| --- | --- | --- |
| 퇴근 후 공원 산책 / 선선해서 좋았다 | "The weather was nice" — **'선선' 의미 약화** | "The weather was cool" — 보존 |
| 산책 안 함 / 내일 공원 예정 | 부정·시제 보존 | 부정·시제 보존 |
| 민수, 김치찌개, 3만 원, KTX | 보존 | 보존 |
| 소요 시간 | 15~49초 | 21~86초 |

→ 의미 보존 우선으로 `qwen2.5:7b` 를 기본값으로 둠. 속도가 중요하면 `settings.json` 의 `translation_model` 을 `qwen3:4b` 로 바꿀 수 있다.

qwen2.5:7b 다섯 스타일 결과에서 확인된 문제:

- **친근한 캐주얼**: 예문 2에서 "내일은 공원에 갈 예정이다" 문장이 **누락**됨 (의미 손실).
- 직장 일상회화: "an KTX ticket" 문법 오류.
- 스타일 간 차이가 작다(대부분 같은 문장).

schema 검증으로는 이런 누락을 잡을 수 없다. 모델·프롬프트 조정 여부는 사용자 검수 후 결정한다.

## 6. 남녀 음성 (R11) — 미해결

MeloTTS 영어 화자는 억양별로만 나뉘고 성별 구분이 없다. 앱은 성별을 추정하지 않고 `unknown` 으로 기록하며, 환경설정의 여성/남성 선택은 **비활성** 상태다. R11 을 충족하려면 추가 음성 엔진 선택이 필요하다.
