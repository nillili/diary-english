# 화면 디자인 변경 계획

작성일: 2026-10-12
요구사항: 화면을 보기 좋게 바꾼다. 시안 4개(A 밝은 미니멀 / B 다크 집중 / C 따뜻한 종이 / D 카드형) 중 **사용자가 B(다크 집중)를 선택**했다.
관련 문서: [의도코드.md](./의도코드.md), [구현계획.md](./구현계획.md), [수동검증.md](./수동검증.md)

## 0. 이 문서를 사용하는 방법

1. 1장 원칙을 먼저 읽는다. 색과 모양만 바꾸고 동작은 바꾸지 않는다.
2. 2장 현재 상태를 확인한다. 1단계는 이미 적용되어 있다.
3. 3장의 단계를 순서대로 진행한다. 단계마다 사용자 확인을 받은 뒤 다음으로 넘어간다.
4. 5장 미확정 항목은 임의로 정하지 않는다. 사용자에게 묻고 답을 받은 뒤 반영한다.

## 1. 원칙

- **동작은 바꾸지 않는다.** 버튼 위치, 탭 구성, 단축키(R·Space), 문구, 상태 표시 규칙은 그대로 둔다.
- **색·모양은 QSS 한 파일에 모은다.** 파이썬 코드에 색을 직접 쓰지 않는다. 바꿀 곳이 흩어지면 다음 변경이 어렵다.
- **새 문구·배지·아이콘을 추가하지 않는다.** 필요해 보이면 먼저 묻는다.
- **읽기 쉬움이 먼저다.** 어두운 바탕에서 글자·테두리·선택 표시가 모두 또렷해야 한다.
- **되돌릴 수 있어야 한다.** theme.qss 를 지우면 기존 기본 모습으로 돌아온다.

## 2. 현재 상태 (1단계 적용 완료)

| 파일 | 변경 | 내용 |
| --- | --- | --- |
| `src/diary_english/ui/theme.qss` | 새 파일 | B 시안의 색·모양 전부 |
| `src/diary_english/__main__.py` | 2줄 추가 | 시작할 때 theme.qss 를 읽어 `app.setStyleSheet` |
| `pyproject.toml` | 2줄 추가 | 패키지에 `*.qss` 포함 |

- 테스트 110개 통과(1 deselected). UI 테스트는 색을 보지 않으므로 영향 없음.
- 아직 커밋하지 않았다.

## 3. 단계

### 1단계 — 전체 테마 적용 (완료)

- 한 일: theme.qss 추가, 시작 시 적용, 패키지 포함.
- 완료 기준: 세 탭 모두 어두운 바탕에 민트 포인트로 보인다. 테스트 통과.
- **남은 일: 사용자가 실제로 실행해 확인한다.**
  ```
  conda activate diary_en && python -m diary_english --dev-fake
  ```
  인증 없음. 세 탭을 모두 눌러 글자가 다 읽히면 통과.

### 2단계 — 읽기 어려운 곳 손보기 (완료, 2026-10-12)

사용자가 고른 대로 `theme.qss` 에만 반영했다.

| 위치 | 문제 | 적용 |
| --- | --- | --- |
| 환경설정 > 음성 성별 | 라디오 동그라미가 어두워 선택 상태가 흐릿 | 고른 쪽을 민트(`#35d0a5`) 채움, 테두리 `#4e5765` |
| 보관함 표 | 고른 줄 색 미정 | 바탕 `#22303a` + 글자 민트 |
| 전체 | 글자가 작다 | 본문 15px, 입력창 16px, 번역문 19px |
| 확인 창 | **버튼 글자가 잘렸다** | `QPushButton` 의 `min-width: 72px` 가 원인. 빼고 좌우 여백 22px 로 |

마지막 항목은 사용자 요청이 아니라 테마가 만든 문제라서 바로 고쳤다.

그대로 두는 것:

- 폴더 선택 창 등 OS 가 그리는 창은 테마가 적용되지 않는다.
- 보관함 검색창(`QLineEdit`)은 따로 꾸미지 않았다. 바탕색은 어둡게 나온다.

### 3단계 — 문서 반영 (완료, 2026-10-12)

- `docs/수동검증.md` 에 M16~M19 추가 (세 탭 전체 / 라디오 / 보관함 선택 줄 / 확인 창 버튼)
- `docs/구현진행.md` 에 "화면 디자인 변경 (2026-10-12)" 절 추가

### 4단계 — 마무리

- 사용자가 "커밋해줘" 라고 말하면 커밋한다. 그 전에는 하지 않는다.
- 푸시도 따로 지시를 받는다.

## 4. 하지 않을 것

- 밝은 테마와 어두운 테마를 바꾸는 설정 항목 추가. (요청에 없다)
- 레이아웃 변경(버튼 위치, 탭 순서, 창 크기, 영역 비율).
- 아이콘 추가·교체, 애니메이션, 그림자 효과.
- 폰트 파일 동봉. 시스템에 있는 `Noto Sans CJK KR` 을 쓰고, 없으면 기본 산세리프로 떨어진다.
- 번역창의 현재 문장 표시 방식 변경. 지금은 `> 문장` 굵게이며 파이썬 코드가 만든다. 바꾸려면 코드 수정이 필요하므로 별도 지시를 받는다.

## 5. 확인한 것 (2026-10-12 사용자 결정)

1. 라디오 버튼 선택 표시 → **민트로 또렷하게**
2. 보관함 선택 줄 → **짙은 바탕 + 민트 글자**
3. 글자 크기 → **조금 키운다** (본문 15px, 번역문 19px)
4. 밝은 테마 → **만들지 않는다.** QSS 는 `theme.qss` 한 파일로 둔다

남은 것: 수동검증 M16~M19 를 사용자가 실제로 실행해서 확인한다.

## 6. 되돌리는 방법

```
git checkout -- src/diary_english/__main__.py pyproject.toml
rm src/diary_english/ui/theme.qss
```

커밋한 뒤라면 해당 커밋 하나만 `git revert` 한다.
