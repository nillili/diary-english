## 추가 변경 (2026-09-25)

- 변환 시 번역을 먼저 보여 주고 "MP3 생성 중: i/n" 표시 (`translation_preview` 신호)
- 번역 지시문을 구어체로 변경: 줄임말·구동사·일상 어휘, 교과서식 표현 금지, 좋은 번역 예시 3개(few-shot) 포함
- 응답에 `examples`(표현 예시 2~4개) 추가: 번역 아래 같은 칸에 회색으로 표시, 음성 생성 안 함, manifest `examples` 에 저장(없는 예전 자료도 읽힘)
- 번역 문장 앞 번호 제거, 일기 입력칸 4줄 높이로 축소
- 실제 번역 확인(qwen2.5:7b): 새 일기 2개는 구어체로 문장별 분리됨. few-shot 예문과 겹치는 일기에서 두 문장이 한 칸에 묶임 1건. "저녁에 … 잠들었다" 가 "before falling asleep for the night" 로 약간 어긋남 — 7B 모델 한계
- 화면 정리: 변환 버튼 옆에 옵션 표시, 재생/정지 옆에 단축키 안내, "한 문장이 끝나면 기다립니다." 삭제, 저장 버튼 옆에 상태 문구
- 번역 줄 수 = 일기 줄 수(빈 줄 제외). 한 줄에 여러 문장이면 한 요소로 번역. 줄 수가 다르면 교정 요청 1회 후 오류. 실제 확인: 예문 6개 모두 줄 수 일치
- Claude API 번역 추가: 환경설정 "Claude API 키" 칸(가림 표시). 키가 있으면 `claude-sonnet-5`(구조화 출력 JSON schema, effort low)로 번역, 없으면 로컬 Ollama. 키는 사용자 결정에 따라 settings.json 에 평문 저장. 줄 수 검증·교정 1회는 두 엔진 공통. 실제 API 호출 검증은 사용자 키 입력 후
